## 关键约束（做任何一项都要守）

1. **只做白名单转发**，新目标必须进白名单，**不做通用代理**。
2. **不存官方系统密码**（除非明确要求，且和校园网密码一样加密存 `~/.szunet/`）。
3. **不代替用户提交**写操作 —— 只读展示 + 跳转。付款、选课、预约的"提交"都要用户自己点。
4. **抄代码前先查许可证** —— AGPL 传染，无 LICENSE 不能用。
5. **办事大厅的加密参数**说明有防爬机制，**别硬编码**。
6. **第三方工具不能替代"必须本人在场"的操作**（如扫签到码选座）。

## 建议的执行顺序

```
第 1 批（零风险，立刻能发）
  A1 自习地图 → A8 校园系统地图 → A2 校历 → A3 电话簿 → A4 GPA
  B1~B4 场地 / 琴房浏览（公开接口）

第 2 批（打通基础设施）
  D1 CAS 会话 → D2 认证态 WebView → D3 本机数据层

第 3 批（登录后解锁）
  C1 课表 → C2 成绩 → C17 电费 → C11 研讨间预约 → C8 场地预约

第 4 批（体验提升）
  C24 邮箱 IMAP → E3 今日看板 → E4 主动提醒

第 5 批（长期）
  E2 响应式网页 → E1 移动端套壳
```
