## 开发约定速查

**界面**

- 唯一源文件 `desktop/index.html`，构建自动同步到 `desktop/assets/` 和
  `internal/ui/assets/`（**这两份是产物，别手改**）。
- 改完必跑 `python desktop/build-windows.py` + `python desktop/smoke_windows.py`（40 项）。
- 硬规矩：① 一屏放下不滚动，内容多用二级菜单分流 ② grid 必须写 `min-height:0`
  ③ `layoutPane()` 窄屏（≤1080px）一律单列 ④ **改 HTML 不动 id**（JS 引用了 11 个 `lg-*`）
  ⑤ `btn-login` / `btn-diag` / `btn-save-cred` 已被概览占用，新页用 `btn-net-*`。

**校园网**

- **「能上外网」≠「已认证」**：登录必须真的走一次协议，不能见外网通就返回成功。
- 判区分清两个函数：`Detect()` 联网时会提前 return、探测字段留零值（判「没探过」看
  `DetectResult.Probed`，别当探失败）；要「掉线会用哪套协议」用 `portal.Probe()`。
- `ac_id` **绝不能写死 1**，统一走 `resolveAcIDWithSource()`：手动 > 缓存 > 跳转 > 猜测。
  探测网址**不能包含认证门户自己**（它必然 302 到自己的登录页并带默认 ac_id=1，是假信号）。
- 深澜的错误信息可能落在 `Error` / `ErrorMsg` / `SucMsg` / `Res` **任意一个**字段，
  只拼前两个会匹配不到（典型：`ip_already_online_error` 的 error 是 `"ok"`）。
- **普通用户不该看到 ac_id 这个词**：输入框默认折叠，只在报相关错误时自动展开。

**发布与仓库**

- 发版 = `git tag beta0.x && git push origin beta0.x`；`beta` 开头自动发成 Pre-release。
- 版本号要改：两个 `main.go` 的 `const version`、README「当前版本」行、
  `make_release.py` 的 README 字符串标题。
- **发布红线**：假数字一律标「演示」或改「待接入」，别让用户把写死的值当真；
  文案别写开发者视角（比如让用户去改 index.html）。
- **仓库是 public 的**：内部规划 / 设计稿 / 内网地址只放 `.local-docs/`（已 gitignore）。
- 提交前：`go build ./... && go vet ./... && gofmt -l`。
