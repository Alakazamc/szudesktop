# 界面重设计方案：不滚动 + 铺满 + 二级菜单

> 2026-09-17 起稿。当前阶段重点：**先把校园网模块做完、把界面打磨好。**

---

## 一、要解决的问题

### 现状

- **8 个主 tab**：概览 / 校园网 / VPN / 教务 / 图书馆 / 一卡通 / 服务 / 设置
- **三栏布局**（左 / 中 / 右），**每栏各自内滚**，靠右下角木牌翻页器（`pg-left` / `pg-mid` / `pg-right`）
- 底部有「服务农田」

### 柯西的要求

> 「我不喜欢在界面中有滚动，所有页面内容都铺完，然后多做二级菜单」

### 要做的事

1. **干掉内滚** —— 内容按"一屏放得下"来设计，超了就拆页，不滚
2. **内容铺满** —— 不留大片空白，用网格填满
3. **加二级菜单** —— 主 tab 下再分层，一层只放得下的量

```

│  二级    │                                              │
│  菜单    │        内容区（CSS Grid 铺满，不滚动）         │
│  （竖排  │                                              │
│  小木牌）│                                              │
│          │                                              │
├──────────┴─────────────────────────────────────────────┤
│  荔宝说话条（底部固定）                                   │
└────────────────────────────────────────────────────────┘
```

**三级不变**（一级 tab → 二级竖排 → 内容），但**任何一级都不滚动**。

| 一级 | 二级 | 每页内容（一屏放下） |
| --- | --- | --- |
| **概览** | 今日 / 系统地图 | 今日：校园网状态卡 + 待办 + 快捷入口 |
| **校园网** | 状态 / 账号 / 诊断 / 时长 | 状态：区域/时长/ac_id/一键登录；诊断：探测结果表格；时长：流量曲线 |
| **校外 VPN** | 连接 / 账号 / 日志 | 连接：状态机 + 按钮；日志：环形缓冲日志 |
| **教务** | 课表 / 成绩 / 考试 / 培养方案 | 课表：周视图；成绩：列表 + GPA |
| **图书馆** | 借阅 / 座位 / 研讨间 | 借阅：在借列表 + 到期；座位：规则速查 |
| **一卡通** | 余额 / 流水 / 充值 | 余额：大数字 + 今日消费；流水：最近 N 条 |
| **服务** | 场地 / 琴房 / 失物招领 | 场地：10 个场地网格；琴房：10 间 |

## 四、不滚动的技术做法

### 4.1 钉死高度

```css
html, body {
  height: 100%;
  overflow: hidden;          /* 页面本身永不滚动 */
}
.app {
  height: 100vh;
  display: grid;
  grid-template-rows: auto auto 1fr auto;   /* 标题 / 一级 / 内容 / 荔宝条 */
}
```

### 4.2 内容区铺满

```css
.stage {
  display: grid;
  grid-template-columns: 168px 1fr;   /* 二级菜单 + 内容 */
  min-height: 0;                      /* 关键：允许子项收缩，否则会被撑破 */
}
.content {
  min-height: 0;
  overflow: hidden;                   /* 内容区也不滚 */
  display: grid;
  grid-template-rows: repeat(var(--rows), 1fr);  /* 按卡片数平分 */
  gap: 12px;
  padding: 12px;
}
```

> ⚠️ **`min-height: 0` 是 grid 布局里最容易漏的一步**。
> grid 子项默认 `min-height: auto`，内容一多就会把容器撑破，
> 加了 `overflow: hidden` 也不管用。必须显式写 `min-height: 0`。

### 4.3 卡片数量自适应

内容区按卡片数自动分行列，保证铺满：

```js
function reflow(box) {
  const n = box.children.length;
  const cols = n <= 2 ? 1 : n <= 6 ? 2 : 3;
  const rows = Math.ceil(n / cols);
  box.style.gridTemplateColumns = `repeat(${cols}, minmax(0, 1fr))`;
  box.style.gridTemplateRows    = `repeat(${rows}, minmax(0, 1fr))`;
}
```

### 4.4 小窗回退

窗口太小时（<900px 高）允许回退成普通滚动，否则内容会挤成一团：

```css
@media (max-height: 760px) {
  .content { overflow: auto; }
}
```

## 五、可以参考的高星项目

| 项目 | Stars | 能参考什么 |
| --- | --- | --- |
| **[nostalgic-css/NES.css](https://github.com/nostalgic-css/NES.css)** | **21.7k** | **8-bit 像素风组件库**（按钮/面板/进度条/对话框）。和我们的星露谷风最接近，可对照检查组件是否齐全（MIT） |
| **[jdan/98.css](https://github.com/jdan/98.css)** | **11.1k** | **窗口 + 标题栏 + 菜单栏结构**。我们的"窗口壳"可以参考它的 `.window` / `.title-bar` 语义化写法（MIT） |
| **[sakofchit/system.css](https://github.com/sakofchit/system.css)** | **3.8k** | 经典桌面风格，窗口容器 + 模态对话框的组织方式 |
| **[botoxparty/XP.css](https://github.com/botoxparty/XP.css)** | **3.0k** | 同上，另一套桌面拟态 |

**怎么用这些参考**：

- **不要引入它们的 CSS**——我们的像素字体和素材已经自成一套，混进来会打架。
- **参考的是结构和交互**，尤其是：
  - NES.css 的**组件清单**（对照看我们缺什么：进度条、对话框、徽章、列表…）
  - 98.css 的**窗口/标题栏语义化**（`div.window > div.title-bar > div.window-body`）
  - 两者都**不依赖 JS**，说明纯 CSS 就能做出现成的效果
